# Ione demo interface contract

The player sees a flooded archive, Ione, her line, a question choice, and Ask / Interrupt. Developer view reveals world state, authored constraints, A/B/C strategy, performance plan, and timeline. It is an optional inspection mode, never the default experience.

The resonance fork is the character's only prominent accessory and state signal. The palette is wet stone (#101a20), pale archive paper (#e8e5d9), aged copper (#ad7950), and restrained sea glass (#81d2c7). Dialogue is placed over the scene with a dark lower gradient; controls sit on a stable bottom band. The generated image is concept art, not a rigged game asset.

Player-visible: location, character, spoken line, question choice, input action, interruption feedback. Developer-only: schema/constraint labels, world tags, montage plan, pending timers, evaluation case IDs, rhythm and semantic strategy controls. The status phrase stays visible in this prototype because it helps verify an interruption; a production game would express most of it through animation and audio.

Acceptance: default load has one scene, no side rails; Developer view opens and closes with a keyboard-accessible button; question selection and Ask / Interrupt remain available in both modes; no claim of UE PIE or live LLM integration. Check desktop and narrow viewport visually before calling the UI final.
