# Ione 游戏场景视觉设计 v2

## 玩家任务与画面层级

玩家进入废土档案站，与伊欧妮面对面交谈，询问记录、路线和档案开启。第一眼先看到人物与她右耳的磁带装置；第二眼读到她的回应；环境只交代“旧档案站仍在工作”这一件事。没有开发者面板、策略选项或调试指标。

## 美术与版式

- 角色：保留用户选定的正视镜头、布丁头金发、旧帽、单侧磁带耳机、绿色工装长外套和靴子；位于左侧完整露出。四张姿态纹理用于 Listening / Speaking / Interrupted / Warning。
- 场景：原创手绘线稿式废土档案站，抽屉、磁带、手摇通信设备和远处废墟构成可辨识的工作地点。低饱和旧纸色，避免之前的写实反光与无意义机械堆叠。
- 接触：无展示台。脚边独立椭圆软阴影贴住地面，使 2D 人物在画面里有落点。
- 交互：深绿灰对话框放在右下，不挡住脸和耳机；双层描边及端点圆饰呼应旧通信设备。人物名、对白和后续输入控件均由 UMG 绘制，不烘焙在背景图里。

## UE 实现

`AAsterGameMode` 创建 `UAsterGameScreenWidget`。屏幕采用 1280×720 设计坐标并按比例缩放；`Ione_ArchiveRoom_Background_v2`、`Ione_ContactShadow`、`Ione_DialogueFrame` 是分层纹理。现有 `BP_IoneNPC` 仍是角色状态和表演事件源，屏幕人物纹理根据 `GetPortraitPose()` 同步；轻微呼吸位移与切换脉冲由 UI Tick 驱动。场景的四种表情是二维姿态切换，不宣称是骨骼动画或完整身体动作。

背景素材使用内置 imagegen 制作，生成提示要求：16:9、原创废土档案/电台工作间、手绘线稿与旧纸配色、左侧留人物站位、右侧可读设备、底部留对话空间、无人物/文字/UI/平台、避免写实 3D 和无意义机械。程序生成的边框与阴影位于 `Tools/make_ione_ui_assets.py`，可以重新生成。

## 验收边界

在 Windows 11、Intel Iris Xe、UE 5.8.4、D3D11 下编译并运行 1280×720 游戏窗口。场景截图位于 `Reports/ue5_ione_scene/scene.png`。此阶段仅完成用户可见场景及由 UE 角色状态驱动的姿态层；自然语言输入和 Agent 事件连接是下一阶段。
